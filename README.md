# Breve

<img src="assets/bonequinho.png" alt="Mascote do Breve" width="96" height="99">

Aprender não precisa tomar horas. O Breve traz notas curtas e perguntas para o canto da sua tela, no seu ritmo.

- Escolha os temas e aprenda um pouco por vez.
- Alterne entre notas e questionários, em português ou inglês.
- Arraste o mascote para o monitor que preferir.
- Atualize pelo app, sempre com sua confirmação.

## Instalar

Requer Apple Silicon, macOS 14+, [Xcode](https://developer.apple.com/xcode/) e [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

```bash
curl -fsSL https://raw.githubusercontent.com/xinnaider/breve/main/install.sh | bash
```

O instalador baixa a release publicada, compila no seu Mac e abre o Breve em Aplicativos. A primeira instalação pode levar alguns minutos.
