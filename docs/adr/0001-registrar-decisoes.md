# 1. Registrar decisões de arquitetura

- **Status:** Aceito
- **Data:** 2026-09-04

## Contexto

O racional de decisões importantes se perde quando fica apenas em conversas.

## Decisão

Registrar decisões arquiteturais relevantes em `docs/adr/`, numeradas sem reuso. ADR aceito não é reescrito; uma reversão cria outro ADR que o substitui.

## Consequências

O contexto fica revisável e versionado, ao custo de manter registros curtos.
